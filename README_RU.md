Минималистичная Android-игра о цепных реакциях, управляемая одним касанием.

</div>

Частицы движутся по почти чёрному полю. У игрока есть одно касание. Оно создаёт расширяющийся импульс; каждая задетая частица может породить новую волну, а новая волна — продолжить реакцию. Вся попытка решается одним выбранным моментом.

Текущая версия исходного кода: **0.8.0** (`versionCode 10`) · Min SDK: **26 (Android 8.0)** · Target SDK: **37**

## ⚡ Идея

1. Наблюдать за полем.
2. Один раз коснуться экрана и разместить единственный импульс.
3. Дать волне активировать соседние частицы.
4. Использовать обычные частицы, усилители, частицы с задержкой и неподвижные якоря для продолжения реакции.
5. Достичь цели до затухания цепи.
6. Улучшать результат на том же детерминированном поле и получать до трёх звёзд.

> Одно касание. Один импульс. Максимальная цепь.

## ✨ Что уже работает

- Управление одним касанием и один импульс на попытку
- **60 детерминированных уровней**, объединённых в шесть глав по 10 уровней
- Главы: **Импульс, Движение, Усиление, Контроль, Резонанс, Хаос**
- Обычные частицы, усилители, задержки и якоря с различным поведением и визуальным языком
- Контекстное обучение базовому правилу и новым игровым паттернам
- Разблокировка уровней, переход дальше, выбор по главам, счёт, 1–3 звезды и сохранение лучших результатов
- **21 локальное достижение** в группах Путь, Мастерство, Цепь и Выносливость
- Экран достижений и статистики с прогрессом прохождения и идеального завершения каждой главы
- Локальная статистика попыток, побед, процента успеха, активированных частиц, лучшей цепи, глубины и счёта
- Локальное хранение через AndroidX DataStore
- Детерминированный повтор уровня и fixed-step симуляция 60 Гц
- Многослойные неоновые волны, следы, вспышки, звук и виброотклик
- Сохраняемые настройки звука, вибрации и уменьшенных эффектов
- Русские и английские ресурсы интерфейса
- Портретная Android-ориентация
- Без аккаунта, backend, аналитики, рекламы, облачной зависимости и разрешения `INTERNET`

## 🧩 Кампания

| Глава | Уровни | Основная идея |
| --- | ---: | --- |
| I · Импульс | 1–10 | Базовая цепная реакция одним касанием |
| II · Движение | 11–20 | Более плотные поля обычных частиц |
| III · Усиление | 21–30 | Дальность усилителей и время задержек |
| IV · Контроль | 31–40 | Якоря и смешанные механики |
| V · Резонанс | 41–50 | Плотные согласованные комбинации |
| VI · Хаос | 51–60 | Полное владение системой |

Уровни используют стабильные seed, поэтому повтор воспроизводит то же логическое испытание. Расширенная кампания защищена детерминированными regression-тестами, включая проверенные выигрышные стартовые точки для уровней 21–60.

## 🎮 Ощущение игры

IMPULSE строится на ясности и нарастании реакции, а не на визуальном шуме:

- **запуск** — пятисекундное фирменное появление IMPULSE приводит в главное меню;
- **ожидание** — холодные голубые частицы спокойно движутся по полю;
- **касание** — из выбранной точки расходится единственный голубой импульс;
- **усилители** — розовые частицы создают увеличенные волны;
- **задержки** — золотые частицы ждут перед распространением волны;
- **якоря** — синие неподвижные частицы служат надёжными ретрансляторами;
- **цепь** — цвета и волны позволяют читать распространение реакции;
- **результат** — размер цепи, цель, глубина, счёт, звёзды, новый рекорд, повтор и следующий уровень показываются без лишних пауз.

Рендеринг может работать с частотой экрана, а игровая логика остаётся детерминированной благодаря fixed-step симуляции 60 Гц.

## ✅ Проверки качества и безопасности

Pull request и push в `main` автоматически проходят unit tests, Android Lint, сборку debug/release, runtime instrumentation tests на API 37, CodeQL, Semgrep, Gitleaks и Qodana. Еженедельная проверка также охватывает минимальный API 26.

Защищённый `main` требует настроенные проверки перед squash merge. Сторонние GitHub Actions закреплены по неизменяемым commit SHA, а workflow используют минимально необходимые permissions.

Об уязвимостях следует сообщать по правилам из [SECURITY.md](SECURITY.md).

## 🔐 Целостность релизов

Официальные релизы запускаются тегами `vMAJOR.MINOR.PATCH`, совпадающими с `versionName`. Release workflow проверяет исходную версию и обязательные checks, собирает приложение с ключом владельца, проверяет подписи APK/AAB и сертификат, создаёт SHA-256 checksums и artifact attestations, после чего публикует GitHub Release. Секреты подписи и keystore не хранятся в репозитории.

Подробности: [docs/RELEASE.md](docs/RELEASE.md).
